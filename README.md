# Horizon — Luxury Landing Page

A single-page, luxury creative showcase for the **Horizon** brand featuring:
- Atmospheric animated ambient gradient background with floating glowing orbs
- Custom full-viewport sparkle & dust particle overlay system
- Sleek video showcase with custom luxury controls (interactive scrubber, duration, time remaining, mute/unmute, and fullscreen toggle)
- Responsive layout strictly locked to 16:9 widescreen format across all devices
- Smooth GSAP-driven scroll animations and brand statement reveal

## Quick Start

```bash
npm install
npm run dev
```

Or open `index.html` directly in any modern browser.
